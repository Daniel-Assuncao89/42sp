 # 	Descrição
 	Esse projeto tem o objetivo de ensinar principios de projeto, além de como criar e usar sua própria biblioteca.

# Instruções
	Clone o projeto e utilize o comando make, dentro da pasta clonada para gerar a biblioteca, inclua nos seus arquivos o *#include* do "libft.h" para utilizar as funções disponiveis na biblioteca. Compile seus arquivos adicionando a libft.a
